# PyMOL

PyMOL is an open-source, user-sponsored molecular visualization software which can produce high quality 3D images of biological macromolecules, such as proteins. Also, it has several functions for manipulating structures and some basic functions to analyze their chemical properties. A large percentage of the figures in journal publications reporting new macromolecular structures are created using PyMOL.

https://github.com/schrodinger/pymol-open-source
