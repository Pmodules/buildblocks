# ORCA

ORCA is a general-purpose quantum chemistry software package used to calculate the electronic structure, energetics, and spectroscopic properties of molecules. Developed primarily by Frank Neese's group at the Max-Planck-Institut für Kohlenforschung and distributed commercially via FACCTs, it runs on Linux, macOS, and Windows and is free for academic use.

https://www.faccts.de/orca/
